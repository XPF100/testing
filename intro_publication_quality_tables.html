Intro to Publication-Quality Tables in R

gtsummary, sjPlot, and table1

1. Overview

In this tutorial you will learn how to:

  • Create descriptive tables using gtsummary::tbl_summary()
  • Create model summary tables using sjPlot::tab_model()
  • Create classic “Table 1” style summary tables using table1::table1()
  • Practice with short exercises along the way

This tutorial is designed to take about 1 hour (including reading, running code, and doing exercises).

5. “Table 1” Style Tables with table1::table1()

The table1 package is designed to create classic “Table 1” style baseline tables found in clinical and epidemiologic papers.

5.1 Basic usage

The main function is table1().

  • You specify a formula of the form:
    ~ var1 + var2 + ... | stratifying_variable
  • The right side of | is the group variable (optional).

Let’s create a Table 1 of baseline characteristics by treatment.

This displays:

  • Columns: each treatment group (+ overall by default)
  • Rows: variables
  • Summary statistics automatically chosen based on type

5.2 Adding labels

You can set labels for variables using the label() function.

5.3 Customizing continuous variables (optional)

You can customize how continuous variables are summarized using render.continuous. For example, showing median and IQR instead of mean and SD.

(This level of customization may be beyond what you need in an intro class, but it’s good to see what’s possible.)
